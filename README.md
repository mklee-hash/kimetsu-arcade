# 귀살 아케이드 (Kimetsu Arcade)

귀멸의 칼날 세계관(다이쇼 시대, 혈귀, 호흡, 등나무, 귀살대 계급)을 모티브로 한 브라우저 게임 네 편 (어린이도 즐길 수 있는 리듬 게임 위주).
주요 인물 여섯 명(카마도 탄지로·아가츠마 젠이츠·렌고쿠 쿄쥬로·하시비라 이노스케·카마도 네즈코·코쵸우 시노부)은 `web/kchars.js`가 Canvas로 직접 그린다(이미지 파일 없음). 로고·원작 음악은 쓰지 않고, 혈귀와 곡은 오리지널이다. 비상업 팬게임이다.
모두 설치 없이 PC(마우스/키보드)와 휴대폰(터치)에서 동작하는 단일 HTML 파일이다.

## 🔗 플레이하기

GitHub Pages가 `main` 브랜치의 `docs/`를 그대로 서빙한다. 주소는 가족끼리만 공유한다
(모든 페이지에 `noindex` 메타가 있어 검색엔진에 올라가지 않는다).

## 게임

| 파일 | 이름 | 장르 | 조작 |
|---|---|---|---|
| `web/slash.html` | 새벽의 일섬 | 스와이프 액션 (과일닌자식) | 누른 채 빠르게 긋기, 스페이스 = 오의 |
| `web/rhythm.html` | 호흡의 박자 | 4레인 리듬 액션 | D F J K / 방향키 / 하단 터치 |
| `web/runner.html` | 호흡 달리기 | 리듬 러너 (어린이용) | 점프 · 베기 버튼 / Space · J |
| `web/mole.html` | 두둥! 혈귀 잡기 | 리듬 두더지 잡기 (어린이용) | 3×3 터치 / QWE·ASD·ZXC |

`web/retired/`에는 아케이드에서 뺀 게임(귀살의 부적, 무한의 밤)이 보관돼 있고 배포되지 않는다.

`web/index.html`은 네 게임으로 가는 시작 페이지다. 결과 화면은 모두 귀살대 계급(癸→甲→柱)으로 평가한다. 柱(주)는 甲보다 높은 최고위 계급이다.

## 공통 규칙

- 대원 프로필: `web/kprofile.js` (전역 `KProfile`). 한 기기를 여러 명이 쓰도록 대원마다 기록을 `kimetsu-arcade:u:<id>:` 접두어로 따로 저장한다(첫 대원은 옛 접두어 `kimetsu-arcade:`를 이어받음). 계급(네 게임 중 최고)에 따라 게임별 능력치(`KProfile.PERKS`)가 오르고, 결과 화면에 계급 상승을 보여 준다.

- 캐릭터 그림: `web/kchars.js` (전역 `KChars`). 호흡별 매핑 물=탄지로, 번개=젠이츠, 화염=렌고쿠, 짐승=이노스케. `web/_chars-preview.html`은 개발용 미리보기로 배포되지 않는다.

- 외부 리소스는 Google Fonts(Nanum Brush Script, Gowun Dodum)뿐. 그래픽은 Canvas/SVG로 절차 생성, 소리는 WebAudio로 합성.
- 기록은 `localStorage`의 `kimetsu-arcade:` 접두사 키에 저장(실패해도 게임은 동작).
- 밤하늘 단일 다크 팔레트: `#0b0e22`(밤) `#efe6d2`(종이) `#d8343f`(피) `#a58bdc`(등나무) `#f2b24a`(새벽).

## 배포 (GitHub Pages)

`web/`을 수정한 뒤 `sh build.sh`로 `docs/`에 복사하고 커밋·푸시한다. Pages는 `main` 브랜치의 `/docs`를 그대로 서빙한다.
